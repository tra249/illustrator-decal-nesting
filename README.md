# Illustrator Decal Nesting

Adobe Illustrator 用のネスティング（自動詰め込み）スクリプトです。
デカールやカッティングシートのパーツを、指定した枠（長方形）の中へ隙間を空けて自動配置します。

![配置例](docs/example.png)

## 特長

- 不定形パーツ（凹形状・複合パス・グループ）に対応
- 隙間をスライダーで調整し、ダイアログを開いたまま何度でも再配置
- 回転刻み（なし / 180° / 90° / 45° / 30° / 15° / 10°）を選択可能。反転はしません
- 複数の枠に対応（上の枠から順に詰め、入りきらない分を次の枠へ）
- 「元に戻す」ボタンで最初の位置と向きに復元

## 動作環境

- Adobe Illustrator 2025 以降（Windows で想定。ExtendScript なので macOS でも動作する見込み）

## 使い方

1. パーツと枠をまとめて選択します。
   - 枠は「塗りなし（または白）の長方形」にしてください。自動で判別します。
   - パーツは1つずつ別オブジェクトにします（グループ・複合パスは可）。全体が1つのグループにまとまっている場合は、中身を個別パーツとして扱います。
2. 「ファイル > スクリプト > その他のスクリプト…」（Ctrl+F12）から `DecalNesting.jsx` を実行します。
3. 設定を調整して「配置」を押します。

スクリプトメニューに常駐させたい場合は、Illustrator の `Presets/ja_JP/スクリプト` フォルダに `DecalNesting.jsx` をコピーして Illustrator を再起動します。

## 設定項目

| 項目 | 説明 |
|---|---|
| 隙間 | パーツ同士の最小間隔（mm） |
| 枠の余白 | 枠の内側に確保する余白（mm） |
| 回転 | 試す回転角の刻み。細かいほど詰まりやすいが遅い |
| 精度 | 判定グリッドのサイズ。細かいほど隙間が設定値に近づくが遅い |
| 試行回数 | 配置順を変えて試す回数。最も良い結果を採用 |

## 仕組み

1. 各パーツのベジェ曲線を折れ線に分割し、回転角ごとにグリッドへラスタライズします。
2. 隙間の半分だけ各パーツを膨張させます。
3. 面積の大きい順に、枠の長辺方向へ最も詰まる位置（Bottom-Left 系ヒューリスティック）を探索して配置します。
4. 配置順をランダムに入れ替えて複数回試し、最良の結果を採用します。

## 制限事項

- ボルト穴などの内側の穴は無視し、外形のみで配置します。
- グリッド判定のため、実際の隙間は設定値よりわずかに大きくなります（1.0 mm グリッドで +1 mm 前後）。
- 隙間はパス形状同士で測ります。線幅は含みません。
- テキストや配置画像は外接矩形として扱います。
